A private locker for your rough mixes. Your band comments straight onto the waveform, you set the running order, and you decide what goes public. Hosted by you. No streaming terms, no licensing, no bs, just tunes.

get it running

Set up Demo Locker for me — read https://raw.githubusercontent.com/usedrobot/demo-locker/main/AGENTS.md and follow it.
npx demo-locker
docker run -d -v demolocker:/data -p 3001:3001 ghcr.io/usedrobot/demo-locker:latest

Claude Code, or any agent that can read a URL and run commands.

The wizard asks where it should live and sets it up.

Multi-arch image, runs on a Pi. One volume holds everything.

public locker

Flip playlists to public to share your music on any site, most importantly your own. For example:

dlisok.com

host it yourself

What to bring:

  • One of these to run it on:
    • A Cloudflare account with an R2 bucket, if you want it to live on the internet, or
    • an old machine or a Raspberry Pi with Docker on it, if you'd rather it live on your own shelf.
  • Your demos.
  • Some friends.
